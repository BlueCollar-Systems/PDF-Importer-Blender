# v1.0.112 test candidate

Dense PDF sheets with qualified round-cap strokes could become obscured by dashed relationship guides in Blender's viewport. These guides joined each visible rounded footprint to the original editable centerline, whose object origin was elsewhere on the sheet. They were native viewport overlays rather than PDF geometry.

After the existing source, surface, area, placement, ownership and material checks succeed, the importer now retains each redundant centerline as a hidden editable source helper. The verified filled footprint remains visible and editable. Original geometry, materials, transforms and parent links are preserved, and the importer leaves the user's relationship-line and other overlay settings alone. Existing sheet framing respects the hidden-helper marker; explicit wire-only output and unqualified source strokes retain their existing behavior.

Replacement requires the original native centerline to have the expected paper depth, unit rigid axes, untrimmed round bevel and unit point radii, with no additional extrusion, offsets, custom bevel/taper geometry or shape keys. The checks run again after the last mutable progress callback. Failure restoration independently attempts every visibility flag, helper marker, original line width and source reference, and incomplete cleanup remains an error.

The native round-stroke probe now checks five synthetic cases—horizontal, vertical, slanted, dot and short strokes—for source area and bounds, visible footprints with hidden parents, saved/reopened hierarchy and continued parent-to-child translation. Source regression tests also cover extra-paint refusal, late changes, wire-only requests and refused or throwing visibility restoration.

The five native product cases passed in Blender 3.1.2 (17.578 seconds) and Blender 5.2.2 LTS (27.141 seconds). Both native processes exited normally. The 5.2 check's outer owner remained failed because it compared the descriptive host string `5.2.2 LTS` to `5.2.2`; that evidence is retained as a test-controller error rather than relabeled as a passing owner. The probe also records Blender's numeric version tuple for future exact host checks.

These cases do not establish whole-sheet pixel parity or universal host compatibility. A newly packaged candidate still requires the separate dense-foundation desktop display check before publication.
