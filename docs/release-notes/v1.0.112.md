# v1.0.112

## What changed

- Rounded line ends on busy sheets no longer get covered by dashed guide lines in the Blender viewport. Each rounded line is shown as one filled shape, and the original editable centerline is kept as a hidden helper. Nothing is deleted, and your overlay settings are not changed.
- The shared PDF core sync check now protects host-specific files that were already reviewed.

## How it was checked

- The automatic checks pass on `main` (test suite, shared-core sync check, release-ZIP smoke check).
- The Blender host matrix last passed on `main` on 2026-10-19 (Blender 3.1.2, 3.6, 4.2, 4.5 and 5.2.2).
- Real Blender test on Windows, Blender 5.2.2 LTS, with the release ZIP installed into a temporary add-on folder: two made-up test PDFs and one real shop sheet were imported, saved as .blend files, and reopened in a fresh Blender. Every object, curve, text item and picture came back the same after reopening.

## Known limits

- Windows 64-bit only. macOS, Linux and Windows on ARM are not supported. Blender 3.1 or newer is required.
- If a PDF uses a font that is not embedded in the file and is not installed on your computer, those words come in as small pictures instead of editable text. The import report lists each one. On the real shop sheet above, a small share of the text came in this way; no text item failed.
- The import aims to match the drawing closely, but it is not guaranteed to be a pixel-perfect copy of the PDF.
- This build was tested headless (no Blender window). The check of a dense sheet in the open Blender window was not repeated for this release.
- On Windows, Blender can sometimes print an access-violation message from its built-in Python when it closes. This was also seen with earlier versions and in checks that do not import anything.
- Large or very busy sheets can take a while to import.

Please report problems with a sample PDF you are allowed to share, and we will fix them in the next update.

## Technical details

The round-stroke change runs only after the existing source, surface, area, placement, ownership and material checks succeed. It requires the original native centerline to have the expected paper depth, unit rigid axes, an untrimmed round bevel and unit point radii, with no extra extrusion, offsets, custom bevel or taper geometry, or shape keys. The checks run again after the last progress callback. If anything fails, every visibility flag, helper marker, original line width and source reference is restored, and incomplete cleanup is reported as an error. Explicit wire-only output and unqualified strokes keep their existing behavior.

The native round-stroke probe checks five made-up cases (horizontal, vertical, slanted, dot and short strokes) for source area and bounds, visible footprints with hidden parents, the saved and reopened hierarchy, and parent-to-child movement. These passed in Blender 3.1.2 and Blender 5.2.2 LTS.
