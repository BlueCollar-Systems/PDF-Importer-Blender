# Blender PDF Importer 1.0.99

Glyphs and Geometry imports now retry helper visibility after Blender registers a newly linked transform helper in its active view layer. Reused glyph outlines previously failed with an object-not-in-view-layer error on dense drawings. The fix retains the selected text representation and exact transforms; a persistent host error still fails and cleans up the owned attempt.

This version also includes the previously committed drawing-list reuse, spatial lookup, and classification improvements, with extraction and recognition parity tests. Source paths, source font programs, dimensions, line widths, and text-mode verification remain in place.

Validation before native candidate acceptance: 567 Python tests and 22 subtests passed, with five optional skips. Production lint and the shared-core integrity check pass. Native all-mode acceptance and publication remain separate release gates.
