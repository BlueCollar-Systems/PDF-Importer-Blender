# Blender PDF Importer 1.0.99

Glyphs and Geometry text modes now import drawings that previously refused to load at all.

- Fixes a failure that made Glyphs and Geometry mode unusable on some sheets. Converting text to outlines created a hidden transform helper, and hiding that helper raised an error whenever it sat outside the scene's view layer. The error was counted against the text item rather than the helper, so the import was refused as incomplete. On the S-505 foundation sheet this lost 308 of 324 text items; the same drawing imported normally in Text, Labels, 3D Text and Raster mode.
- The helper is still hidden, by a route that always applies, and a helper that cannot be hidden no longer costs the text it belongs to.

Validation: 560 tests passed, two skipped, and 22 subtests passed. All six text modes were re-run against the S-505 48x36 markup sheet on Blender 5.2: Labels, Text and 3D Text deliver 7,856 objects and Raster 1,134, unchanged from 1.0.98; Glyphs now completes with 3,675 curve outlines and Geometry with 4,077 meshes, where both previously failed. This verifies the tested drawing and failure classes, not universal PDF support.
