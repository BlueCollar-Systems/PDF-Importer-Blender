# Blender PDF Importer 1.0.110

A dense sheet retains its qualified round-ended strokes and editable
centerlines. Filled footprints share one scene update before their original
surface, area, material and placement checks. Density alone does not skip
round ends. Cancellation removes the unfinished batch and verifies restoration
of the original line widths and references. Source capsule ownership is
indexed once before cleanup while retaining uniqueness and unchanged-point
checks.

An inferred space uses an empty glyph only when the PDF's original subset font
proves that glyph is blank. Visible or uncertain glyphs retain the existing
reported fallback. Convex linear fills and clips use exact intersections;
exactly collinear fills are recorded as nonpainting, and unsupported
intersections remain reported.

The preceding test candidate completed import, save and fresh-process reopen
checks on a dense foundation sheet in Blender 5.2.2. Broader desktop and
rendered visual comparison checks remain pending.

For a Windows upgrade, disable the add-on, save Preferences if needed, close all
Blender windows, reopen, install the new ZIP before re-enabling, then enable the
add-on. This lets Blender replace the PDF reader's files completely.

Version 1.0.110. The release ZIP is still Windows 64-bit only.
