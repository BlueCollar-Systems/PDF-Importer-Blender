# Blender PDF Importer 1.0.110

A dense sheet of tiny round-ended lines finishes. Those lines stay editable
centerlines. A separate filled round end is still built when the page has 64
or fewer of them. On a sheet with thousands, the import says the round ends
were skipped so the sheet can finish. Cancelling still stops that work.

A space that a subset font does not map is treated as blank ink. Those lines
are no longer left unfinished as unverified synthetic spaces.

For a Windows upgrade, disable the add-on, save Preferences if needed, close all
Blender windows, reopen, install the new ZIP before re-enabling, then enable the
add-on. This lets Blender replace the PDF reader's files completely.

Version 1.0.110. The release ZIP is still Windows 64-bit only.
