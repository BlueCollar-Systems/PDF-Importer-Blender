# Blender PDF Importer 1.0.98

Dense drawings such as the S-505 foundation sheet now retain their native vectors in Auto mode. Imports frame the actual sheet, and the text-transform helpers stay hidden so their axes do not appear as lines standing out of the drawing.

- Splits large batches into manageable curve objects without dropping source paths, and writes every spline point reliably on older Blender APIs.
- Frames spline geometry when Blender's object bounds are collapsed; zoom is no longer reset by stale bounds.
- Preserves source-width visible strokes, glyph-scaled helper sizes, current text transform precision and main's recent import-performance improvements.
- Handles sparse PDF object tables without aborting the completed import; the optional interactive-feature audit records when inspection is partial.

Validation: 555 tests passed, two skipped, and 22 subtests passed on Python 3.12. Blender 5.2.1 imported the S-505 drawing with all 324 source text items represented by 3,523 visible font objects, 3,523 hidden helpers, no whole-page raster replacement, working focus/zoom, and matching visibility after saving and reopening. This verifies the tested drawing and failure classes, not universal PDF support.
