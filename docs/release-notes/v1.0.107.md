# Blender PDF Importer 1.0.107

This release is everything that landed on main after v1.0.106. Colors follow the PDF, a problem letter no longer throws away the rest of the drawing, and more text stays editable.

## What you will notice

- **Colors match the PDF.** A new import starts in Source Accurate instead of a grey preview. Blues, photos, and gradients stay the color they are on the page instead of washing pale. A picture with a real transparent edge mixes correctly. Gray or colored paper stays. A near-white page fill is still replaced by the white page background.
- **One bad letter no longer deletes the sheet.** If a letter at the edge of a sheet cannot be trimmed, that letter stays as drawn and the rest of the sheet still comes in. Later sheets are not skipped. The report names the letter that needs a look. Starting the import again after it has already finished says there is nothing left to resume, instead of "PDF import failed". Press Esc while an import is running to stop it and keep the pages already built, then turn on Resume to continue.
- **Clipped shapes stay inside the box.** A circle or other curve painted only inside a rectangle is cut to that rectangle. If the clip itself is not a rectangle, that fill is left out instead of flooding the page. A letter that was clipped correctly on a sheet stacked away from the origin is not flagged as a leak. A real gap of about a millimetre still fails.
- **More text stays editable.** A CAD or Tekla drawing that names Arial (or another font on the computer) without storing the font in the PDF comes in as real text when the PDF's own widths prove it is that font, and the letters are the ones the page draws. A line is one text object when the spacing matches the font. If that one object cannot be placed, the line is built letter by letter.
- **Glyphs works on older Blender.** Choosing Glyphs turns text into curve outlines on Blender 3.1 through 4.2. On those versions it used to stay as text, and on 3.1 it could crash.
- **A font problem no longer cancels the page.** Hidden OCR letters on a scan are left out, so the scan and the drawing underneath stay. A subset font with a short metrics table is repaired and the letters import. A space with no width is left out. A painted word space on a line that crosses the sheet edge stays with the line. A JPEG2000 picture with a soft mask no longer stops the import.
- **The dialog matches the switches.** A Z offset of 0 means flat. The Compact gap shows only for Compact and starts at 5%. Labels is listed last, because Blender makes it flat text. Height offsets sit under Advanced. The default cube is hidden from renders. The slow extra self-checks run only when Audit import is on.
- **Drag a PDF onto Blender 4.1 or newer** to open the import options for that file. File > Import still works, including on older Blender. The add-on says it is Windows 64-bit only, and that reinstalling will not make it run on a Mac, Linux, or Windows on ARM.
- **A folder of PDFs keeps one result per file.** Batch summaries no longer count one drawing as both passed and failed, and two drawings with the same name no longer overwrite each other's report. Source folders are kept in the summary.

Version 1.0.107. The release ZIP is still Windows 64-bit only.
