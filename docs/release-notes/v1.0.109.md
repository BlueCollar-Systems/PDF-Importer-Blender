# Blender PDF Importer 1.0.109

PDF holes stay empty instead of being painted as separate solid faces. Even-odd
contours are filled together, including a lone crossing contour. Simple nested
and disjoint nonzero fills preserve the producer's winding through a unique
original directed source path, so opposite-winding holes and same-winding solid
interiors both work.

Isolated opaque round-ended straight lines gain an editable filled boundary.
Their original centerlines remain editable, and moving a centerline moves its
boundary. The native rational curve is checked against the source area; hosts
that evaluate it differently use a reported editable cubic approximation with
a bounded circular error.

Complex or unproven fill topology remains cancellable and bounded. Its original
paths stay editable, and the report explicitly identifies incomplete fill
delivery. Raster mode remains available for full-page appearance. Crossing or
touching nonzero contours, ambiguous original direction, overlapping round
strokes and projecting-square stroke extents have separate limitations.

For a Windows upgrade, disable the add-on, save Preferences if needed, close all
Blender windows, reopen, install the new ZIP before re-enabling, then enable the
add-on. This lets Blender replace the PDF reader's files completely.

This source change has bounded headless geometry and save/reopen checks on
Blender 3.1.2 and 5.2.2. Desktop package acceptance and publication are tracked
separately. The optional shape-extrusion interface remains disabled; editable
3D Text continues to work.
