# Blender PDF Importer 1.0.101

Final translucent rectangle annotations now remain above native text, using the PDF's raw opacity and exact centered stroke width. The importer qualifies these annotations against the complete final paint sequence and renderer SVG evidence for clipping, transform, miter limit, color and width. Their source XY stays on the page plane; an explicit display offset separates paint from extruded text. Final-page raster text crops are excluded from the new paint, preventing a second tint. Unsupported paint arrangements keep the existing source construction.

Native PDF text uses verified unlit ink, preventing host lighting from graying black letters or adding highlights to 3D text. High Contrast and Blueprint keep foreground text distinct from white knockout backgrounds and reversed lettering. Source Accurate retains source RGB; native color-management settings still affect the displayed appearance. Pages with final transparent annotations open in material preview so opacity is visible.

Each automatic import report and its related sidecars now use a unique Blender run directory. Separate applications or imports of identically named PDFs cannot overwrite each other's default reports. Explicit report paths continue to work.

The shared extraction model retains raw source paint RGB, opacity and order alongside existing composited colors. Source text, fonts, source geometry and representation verification stay intact. Native all-mode acceptance and publication are separate release gates; private corpus files and native artifacts are not distributed in this package.

Validation before native candidate acceptance: 626 Python tests and 22 subtests pass, with five optional skips. Production lint and the local shared-core integrity check pass.
